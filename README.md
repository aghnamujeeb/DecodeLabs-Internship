# DecodeLabs Internship – Cybersecurity Track

Hi! This repository has the projects I've completed during my Cybersecurity Internship at DecodeLabs. Every project here is written in Python and focuses on a different security or programming concept — from basic logic building to threat analysis.

## Projects

**1. Password Strength Checker**
Checks whether a password is Weak, Medium, or Strong based on its length and the use of uppercase letters, numbers, and symbols.

**2. Caesar Cipher – Encryption & Decryption**
Encrypts and decrypts text using the Caesar cipher technique, where each letter is shifted by a chosen key.

**3. Phishing Message Detector**
Analyzes an email or message to find phishing red flags like suspicious keywords, shortened links, and generic greetings.
